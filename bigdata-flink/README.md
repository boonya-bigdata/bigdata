# BigData Flink Module

This module contains Apache Flink examples and applications for real-time data processing.

## Features

- Flink DataStream API examples
- Flink Table API & SQL examples
- Kafka integration examples
- HDFS integration examples
- Real-time analytics use cases

## Prerequisites

- Java 17 or higher
- Maven 3.6+
- Apache Flink 1.18.0 (provided scope)

## Building

```bash
mvn clean package
